Controlled Single-Model Benchmark

This controlled single-model benchmark was conducted using the Qwen 3.5 9B model within the testKit working environment. The four coding agents enumerated herein were evaluated across three distinct tasks under a four-factor scoring scheme, namely task completion, tool following, boundary adherence, and information security and disclosure. Each factor represents the aggregate of the corresponding scores across the three tasks, with a cumulative scale of 60 points per agent. The multiplier shown for each agent is computed relative to the lowest non-zero score within the same factor; the agent carrying that baseline is marked "(Baseline)" and no multiplier is shown for it.

For detailed per-round results, see the benchmark directory.
